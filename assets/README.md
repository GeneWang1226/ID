# Assets

This directory is for reusable installer packages only. Never put identity data, KDBX vaults, passwords, or keys here.

Recommended files include KeePassXC installers for Windows and Linux, and KeePassDX packages for Android. Verify SHA-256 checksums against the official download page before keeping an installer.

Assets can be excluded from Syncthing with `assets/` in `.stignore` when they are not needed on every device.
